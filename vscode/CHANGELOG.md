# Changelog

## 1.1.3
- On/off switch (Mac): Control+Option+F, or click Focus: ON in the menu bar. It says "Focus Guard off" / "Focus Guard on".

## 1.1.2
- Click to stay: Focus Guard now stays quiet everywhere until you go back to VS Code yourself (no more prompts in the meantime).

## 1.1.1
- Several VS Code windows open: Focus Guard brings back the one you last typed into, not just the one macOS used last.

## 1.1.0
- First VS Code extension release: starts Focus Guard on macOS (built on your Mac) and Windows (new helper).
- macOS: waits for the Accessibility switch instead of quitting, and says so out loud.
